# Telegram 聊天平台接入指南

Lingo Mate 支持通过 Telegram 私聊使用聊天助手：在聊天中收藏单词（`/save apple` 或自然语言"帮我记住 apple"）、进行学习问答。聊天收藏与桌面词库共享同一份数据，在桌面"已记录"页面立即可见。

## 接入步骤

1. 在 Telegram 中找 [@BotFather](https://t.me/BotFather) 创建一个 Bot，获得 Token（形如 `123456:ABC-DEF…`）。
2. 打开 Lingo Mate 桌面端 → 设置 → 聊天平台，粘贴 Token 并点击"连接"。
   - Token 仅保存在本机系统安全存储（macOS Keychain 等）加密后的文件中，不回读明文、不写入日志。
   - 应用使用 long polling 接收消息，不需要公网地址，也不会部署任何回调服务。
   - Token 失效或需要更换 Bot 时，在已有连接下点击“更新 Bot Token / 更换机器人”；更换 Bot 后需重新绑定账号。
3. 在"账号绑定"中点击"生成绑定码"，获得 6 位短时有效（10 分钟、一次性）的绑定码。
4. 在 Telegram 中向你的 Bot 发送 `/start <绑定码>`（例如 `/start AB23CD`）。
5. 回到桌面端，核对显示的 Telegram 账号信息后点击"确认绑定"。
   - 绑定码输错 5 次会作废，重新生成即可。
   - 每个 Bot 只能绑定一个 Telegram 账号；更换 Bot Token 会清除原绑定，需重新绑定。

绑定完成后即可在私聊中使用：

- 直接发消息：学习问答（与桌面对话相互独立，共享词库）。
- `/save apple, banana`：直接收藏单词。
- 自然语言："帮我记住 apple" → 机器人会列出识别到的词和学习语言，按提示回复 `/confirm <操作 ID>` 确认收藏，`/cancel` 取消。
- `/new`：开启全新对话上下文（有任务运行、排队或待确认时会拒绝，先 `/cancel`）。
- `/cancel`：立即取消当前执行与排队任务，并作废待确认操作；已提交的收藏不会回滚。
- `/help`：查看支持的命令。

## 解绑

设置 → 聊天平台 → 账号绑定 → 解绑（需确认）。解绑后：

- 该 Telegram 账号立即失去访问权限（模型、词库、会话）。
- 运行与排队中的任务被取消，待确认操作与未发送的回复被丢弃。
- 已经保存的词条不受影响。

## 离线限制

- 消息接收依赖桌面应用运行：应用退出、系统休眠或断网期间，Telegram 消息不会自动处理。
- 应用恢复后会处理积压消息，但超过有效期（15 分钟）的写入请求会被标记过期并不执行，需重新发送。
- 重启后：已完成的收藏结果会补发；结果不明确的操作会提示核对词库，不会盲目重跑；旧的自然语言收藏确认会失效，需重新发起。
- 同一 Bot 只允许一个轮询实例：如果应用被重复启动（或另有程序在消费该 Bot 的 getUpdates），连接会以"重复轮询"错误停止。

## 故障排查

| 现象                           | 处理                                                                                                          |
| ------------------------------ | ------------------------------------------------------------------------------------------------------------- |
| 连接异常：Token 无效           | Token 已被撤销或不正确，在 @BotFather 重新获取并在设置中更新。                                                |
| 连接异常：Webhook 冲突         | 该 Bot 设置过 Webhook。请在 @BotFather 中删除该 Bot 的 Webhook 或换用新 Bot；本应用不会自动删除已有 Webhook。 |
| 连接异常：重复轮询             | 另一个进程在读取同一 Bot 的消息（例如应用开了两份）。关闭多余实例后点击"恢复连接"。                           |
| 连接异常：网络错误             | 网络暂时不可用，恢复后会自动退避重连；长时间未恢复可手动"恢复连接"。                                          |
| 生成绑定码后 /start 提示不正确 | 核对码的拼写；新码会替换旧码，以最新生成的为准。                                                              |
| 消息没有回应                   | 确认应用正在运行且连接状态为"已连接"；离线期间的消息请重新发送。                                              |
| 收藏结果未知                   | 机器人会提示"结果未知，请核对词库"；在桌面"已记录"页确认，未保存则重新发起。                                  |

## 隐私与安全边界

- 平台消息与模型输出均按 schema 校验后才进入内部流程；远程能力只有白名单命令，不存在远程文件、SQL、系统命令或删除能力。
- 外部会话与桌面对话完全隔离：桌面会话列表无法读取、也无法通过猜测 sessionId 加载外部聊天历史。
- 未绑定账号发送的消息不保存正文；不支持的事件（群聊、图片、编辑消息等）不保存内容，只推进接收游标。
- 每次执行与投递前都会重新校验绑定；Token 只存在于主进程安全存储。
