# `/concept` 独立 LangGraph 流程

- 日期：2026-10-22
- 状态：已实施
- 分支：`feature/concept-langgraph-agent`（基于干净的 `main`）

## 实现

- 将概念讲解从普通回复图中拆成 `START → explain → END`。Python 入口只根据最新 user 消息选择概念图；既有命令边界、空命令、特殊空白和普通追问行为不变。
- 专用图使用原有 Prompt，一次 `model.reply` 调用直接流式回复。解释使用界面语言，例句使用学习语言；原始命令及上下文、持久化、用量、取消、显式重试及故障语义保持一致。
- 共用模块持有运行初态、宿主调用类型、错误类型及权限／预算检查，避免图与服务之间循环引用。Prompt 上限 4096 UTF-16 单元，统一核对历史输入、输出、模型调用和步数。
- 单节点回复图允许 LangGraph 完成终态检查所需的额外调度轮次；单步预算可完成一次回复，零步预算在调用宿主前明确失败。
- 协议继续为 v4，外部仍提交 `conversation`，不新增 IPC、运行接口、权限或数据库迁移。重新构建 Python 冻结包；不新增多阶段生成、查询工具、自动重试或回退。

## 验证

先新增专用图测试并确认因模块尚未实现而失败，再实现拆分和共用校验。测试覆盖路由、完整终态、单次调用、语言、权限、UTF-16 输入／输出和 Prompt 上限、调用／步数预算、取消传播与宿主失败。

真实 Python 管道覆盖命令边界、原始消息、流式内容不重复、会话持久化、取消与显式重试、模型失败、崩溃与后续新请求重启；沿用用量集成测试确认每次概念任务只记录一次模型调用。冻结包烟测覆盖中英文 Prompt、流式、失败、取消、迟到结果和崩溃后重试。Electron 覆盖实际发送给本地假模型的中英文指令及完整流式回复，并将开发解释器和冻结包的取消／崩溃／重试场景改为概念命令。
