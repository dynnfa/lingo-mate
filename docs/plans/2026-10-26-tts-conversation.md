# `/tts` 对话语音技能

状态：已实施

## 已确认行为

- `/tts 英文纯文本` 直接生成 HeadTTS 音频，加入行动选择器；空参数不进入普通对话。
- 首条会话使用本地原文摘要标题，全程不读取模型配置、不调用 LLM。
- 助手消息展示原文和播放器，等待点击播放；支持暂停、继续、停止、重播与时间显示。
- 点词跳到逐词时间轴的起点并保持播放状态；保留空白、标点、文本选择及键盘操作。
- 所有朗读取消底部播放器；原有扬声器保留开始／停止并在原位显示状态及安全错误。

## 实现

- 协议 v11 的 Python 单节点图仅允许 `tts.synthesize`，模型预算为 0，宿主调用与步骤各 1，含启动截止 180 秒。
- 原文及成果留在宿主，Python 仅交换回执；核验图完成后才原子保存音频与报告。
- SQLite v12 迁移扩展技能执行并新增 WAV BLOB 成果表，保存设置、模型版本与逐词时间轴。回复保存失败时显式重试复用成果。
- 消息携带安全 `speech` 描述；`speech.loadConversationAudio({sessionId, messageId})` 按需读取并校验关联和音频，缺失／损坏不自动重合成。
- 播放复用单一控制器，隔离迟到结果；会话、页面切换与来源卸载停止播放。
- 沿用英语、4,000 UTF-16 单元、120 秒、8 MiB 和当前音色／语速限制；双语静态资源同步更新。
