# 已记录页面骨架实现计划

- 日期：2026-09-08
- 状态：待实施

## 目标与范围

点击会话侧栏的「已记录」，进入独立的已记录页面。页面参考现有 Settings 的左右分栏布局：左侧提供返回入口、页面标题和菜单，目前仅有 Vocabulary；右侧只预留空白内容容器。

本阶段只实现导航和页面骨架，不开发词汇列表、词汇详情、搜索、筛选、增删改、数据读取或加载占位动画，不新增 IPC、数据库或 Core 能力。

## 当前代码基线

- `src/renderer/src/App.tsx`：使用 `AppView = 'conversation' | 'settings'` 管理页面切换；「已记录」按钮已有图标和翻译，但未绑定点击行为。
- `src/renderer/src/settings/SettingsPage.tsx`：已有左侧返回按钮、标题、选中菜单和右侧内容区，可作为布局与交互参考。
- `src/renderer/src/assets/main.css`：已有设置页两栏布局、菜单选中样式及窄窗口适配。
- 设置页显示时，对话视图保持挂载并隐藏，以保留输入草稿与滚动状态；新页面沿用这一方式。

## 页面结构与交互

```text
┌──────────────────┬──────────────────────────────────────┐
│ ‹ 返回           │                                      │
│ 已记录           │                                      │
│                  │          空白内容容器                │
│ Vocabulary（选中）│                                      │
│                  │                                      │
└──────────────────┴──────────────────────────────────────┘
```

1. 点击「已记录」切换整个应用内容区，不打开弹窗或新 Electron 窗口。
2. 左侧菜单的宽度、间距、分隔线、悬停、选中和焦点样式与 Settings 保持一致。
3. 菜单仅提供 `vocabulary`，进入时默认选中；重复点击保持当前页面，不触发数据请求。菜单显示使用翻译资源：中文「词汇」，英文「Vocabulary」。
4. 右侧仅保留可供后续功能接入的布局容器，不渲染详情组件、标题、说明、示例数据或空状态文案。
5. 返回按钮及 Escape 返回原会话视图；进入时焦点移至返回按钮，退出后焦点回到「已记录」入口。
6. 切页保留当前会话、消息、未发送草稿及滚动位置；在途对话沿用当前生命周期继续运行，切页本身不取消或重发请求。
7. 隐藏的会话视图不能参与键盘焦点导航；新页面使用语义化导航、原生按钮及 `aria-current` 标识选中项。

## 实施步骤

### 1. 新增独立页面组件

新增 `src/renderer/src/recorded/RecordedPage.tsx`，接收 `onExit: () => void`，负责页面骨架、返回交互与进入焦点。

左侧仅渲染一个 Vocabulary 菜单按钮及选中状态；当前只有一个菜单，无需多余的动态注册机制或详情路由。右侧保留空白容器。

### 2. 接入应用导航

在 `App.tsx` 的 `AppView` 中加入 `'recorded'`，为现有「已记录」按钮绑定页面切换并添加入口 ref。

将对话视图隐藏条件调整为 `activeView !== 'conversation'`，按当前视图渲染 `RecordedPage` 或 `SettingsPage`。扩展返回焦点逻辑，根据离开的页面恢复到对应入口，保留设置页现有行为。

沿用现有本地视图状态管理，本阶段无需引入 URL 路由或调整全局导航架构。

### 3. 样式与国际化

- 在 `main.css` 中添加已记录页样式，参考设置页现有布局参数；可通过组合选择器共享纯布局规则，不将新页面耦合到设置页业务组件或数据 hooks。
- 右侧容器填满剩余空间，沿用现有窗口断点策略，避免横向溢出；保持按钮可达和焦点轮廓清晰。
- 在 `src/renderer/src/i18n/locales/zh-CN/common.json` 和 `en/common.json` 同步增加 `recorded.title`、`recorded.back`、`recorded.menuLabel`、`recorded.sections.vocabulary`。
- 入口继续使用 `sidebar.menuRecorded`；页面标题、按钮和无障碍标签统一读取翻译 key。

### 4. 组件验证

- 新增 `src/renderer/src/recorded/__tests__/RecordedPage.test.tsx`：验证仅有 Vocabulary 菜单且默认选中、右侧容器为空、返回按钮与 Escape 调用退出、初始焦点正确。
- 扩展 `src/renderer/src/__tests__/App.test.tsx`：验证点击入口打开新页、对话视图隐藏、返回后草稿和会话保留、焦点恢复正确，以及设置页导航未被影响。
- 覆盖中英文菜单与页面无障碍名称，不依赖真实模型请求。

## 验收标准

- 「已记录」入口可进入独立页面，显示与设置页风格一致的左右分栏骨架。
- 左侧只有一个 Vocabulary 菜单项并默认选中；右侧保持空白。
- 返回按钮、Escape 和键盘焦点正常；来回切换不丢失会话与输入草稿。
- 未引入词汇数据请求、详情实现或跨进程接口变更。
- 中英文资源完整，常规及窄窗口尺寸下布局正常。
