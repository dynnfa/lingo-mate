# `/synonym` 完整迁移至 Python / LangGraph

- 日期：2026-10-22
- 状态：已实施
- 分支：`feature/synonym-langgraph-agent`（基于 `feature/concept-langgraph-agent` 的 `5c949ec`）

## 实现

- Python 持有近义词 Prompt 和 `prepare → select → decide ↔ apply → finish` 图，按输入顺序处理，保留分组策略与 Gemini 单次多工具纠正。TS 只执行单轮模型传输与受控宿主能力；完整消息、签名／思考、工具参数和结果留在宿主。
- 协议升级 v5，增加 `synonym` 任务和能力、四个专用宿主操作与 `synonym_result`；同步 Zod、生成 schema、共享契约、握手及 manifest。
- 宿主绑定运行、词项、轮次和待执行决策，保留四个工具的分页／分组写入授权和逐词原子事务。Main 装配单一串行模块，跨会话批次共享新分组。
- 每批 20 项、每词 60 秒／52 轮／50 页；取得串行执行权后总截止 180 秒，包含引擎启动。模型／非模型宿主调用／步骤上限 1040／1061／2200；实际模型输入 65,536、累计安全回执 524,288 UTF-16 单元，Prompt 与帧限制保持原值，其他任务预算不放宽。
- 取消保留已提交词并显示本地报告；引擎、协议与批次超时明确失败，报告保持未完成。显式重试跳过已提交、已有和无法识别项；完整报告仅恢复回复。删除 TS Agent 循环和 Prompt，无数据库迁移、自动重放或回退。

## 验证
