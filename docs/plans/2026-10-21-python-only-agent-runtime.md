# Python 成为唯一 Agent 运行时

- 日期：2026-10-21
- 状态：实施中（代码及 macOS arm64 本机验收完成，其他 OS/CPU 原生 CI 待验收）

## 目标与职责

普通对话与 `/concept` 始终经过 Python，移除运行时选择参数及 TS 直跑分支。Python 持有任务识别、Prompt 和执行流程；TS 保留模型传输、凭据、会话持久化、用量统计、权限和领域校验。显式技能、标题及练习后续迁移，未来新增 Agent 策略和工作流统一写在 Python。

## 实施

- Main 无条件装配 Python runtime，ConversationModule 必须注入 runtime。本地模拟模型同样经过 Python，进程仍在首个 Agent 请求时启动。
- 将普通对话、概念讲解 Prompt 和 ECMAScript 空白语义的命令识别迁至 Python；TS 模型适配器只发送显式 `systemPrompt`。标题调用方继续提供自己的 Prompt。
- 私有协议升级至 v2，外部只提交 `conversation`，不再提交 `word-concept`。`model.reply` 必须携带不超过 4096 个 UTF-16 单元的系统指令，两端校验实际 Prompt 和绑定历史的总输入预算。
- 保留 `LINGO_MATE_AGENT_BUNDLE`、首次请求启动、失败不回退、不自动重放、取消、重试、退出清理及宿主安全边界。
- 同步指南、ADR 和长期记忆计划；原试点记录作为历史保留，不代表当前运行方式。记忆计划继续保持待实施。

## 验证

按 TDD 验证 Python 生成指令、宿主拒绝非法参数和实际输入预算、命令统一交给 runtime。保留会话终态、消息身份、取消重试、独立标题及模型配置快照的回归测试。真实 JSONL 集成验证完整会话入口到 Python Prompt 和模型宿主的执行，Electron 测试默认走 Python。

所有数据库和用户目录验证只使用内存或临时数据，不执行真实用户数据库迁移。

2026-10-21，本机 macOS arm64 验收记录：

- 锁定 Python 环境同步、lint、typecheck、应用构建和协议生成物检查通过。
- TypeScript 全量 139 个测试文件、1608 个测试通过；Python 68 个测试通过，Ruff 和严格 mypy 通过。
- `pnpm test:electron`：49 个用例通过，安装布局用例默认跳过；随后构建 `electron-builder --dir` 并单独启用安装布局用例，1 个用例通过。开发解释器、冻结包和安装布局均验证流式、概念命令、取消、崩溃重试和退出。
- 原生 Python 冻结运行包构建通过。空 PATH 烟测通过握手、流式、取消、迟到结果、崩溃、重启和退出；运行包 manifest 为协议 v2。
- 迁移后的普通对话和概念讲解 Prompt 在两种界面语言下与原 TS 指令逐字一致。
- 所有验证仅使用受控替身、回环假模型、内存数据库及临时用户目录。
