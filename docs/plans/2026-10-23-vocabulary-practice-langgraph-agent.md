# 词汇练习批改迁移至 Python / LangGraph

- 日期：2026-10-23
- 状态：已实施
- 分支：`feature/vocabulary-practice-agent-engine`（基于 main `0234cb7`）

## 实现

- Python 持有原有双语系统 Prompt、多轮批改、标红工具编排和最多两次补标指令。独立 `vocabulary-practice-review` 任务进入 `prepare → model → apply / correct → model → finish` 图，全对直接结束，最多 8 轮。
- TS 保留答案和词条快照、参考释义、完整模型消息、工具参数、标记、最终反馈、模型配置／传输／用量及错题事务。Python 只接收轮次、分类、输入大小与安全回执；图终态通过核验后才返回批改结果。
- 宿主拒绝越权、错序、重复／并发模型调用、重复调用 ID、篡改 Prompt、伪造完成、外部词条 ID 及矛盾反馈。取消、进程退出及迟到结果不发布标记，不保存不完整错题；后续用户显式提交可以启动新运行。
- 保留 `mark_text_red`、语义判定、无参考释义容错、多调用标红、按 ID 关联工具回执、模型 reasoning 字段和原有供应商工具请求策略；工具参数错误可由模型在剩余轮次修正。无 TS Agent 直跑或失败请求自动重放。
- 练习会话、随机抽样、requestId 成功缓存与整批错题幂等保存保持原样；新增 IPC 窗口归属校验，禁止其他窗口批改／取消／替换会话，owner 销毁时释放并取消。Renderer、Preload 方法和页面交互保持现状，复用现有中英文引擎错误资源。
- 模型／非模型宿主调用／步骤预算为 8／10／18；含启动截止 120 秒，供应商请求 60 秒。完整消息和工具定义的实际输入上限 65,536 UTF-16 单元，累计安全回执和 Prompt 上限均为 4,096；单轮模型消息上限 65,536。
- 协议 v10，同步 Zod 生成 schema、共享契约、握手、故障测试引擎及运行包 manifest；旧包必须重建。更新项目指南、ADR、架构说明及引擎 README。无数据库迁移或真实用户数据变更。
