# `/vocabulary` 完整迁移至 Python / LangGraph

- 日期：2026-10-21
- 状态：已实施
- 分支：`feature/vocabulary-langgraph-agent`（基于 `feature/python-only-agent-runtime`）

## 实施目标

保留选择器、批量输入、阶段提示、收藏报告、取消和重试交互。Python 持有分析 Prompt 和批量执行图，TS 保留输入规范化、去重、领域校验、模型传输、凭据、用量及事务持久化。不新增数据库迁移，不使用真实用户数据库验证。

## 实现与契约

- 图为 `prepare → analyze → finalize`，分析节点使用两个 worker，每批最多 20 词，每个新词一次请求；已有词和批内重复项不请求模型。无自动重试、回退、checkpoint 或跨运行状态。
- 协议升级 v3：新增 vocabulary 任务、`vocabulary.prepare`、`model.vocabulary`、安全回执及 `vocabulary_result`。握手、生成 schema、共享契约、manifest 和冻结包同步更新。
- 专用运行接口 `runVocabulary` 共用现有 Python 子进程，词汇最多两个在途分析调用；其他运行仍限一个。宿主绑定原始词项，拒绝重复索引、非法调用归属、超预算及额外权限字段。
- TS 的运行级领域账本保留已校验内容、入库系统字段及原始索引映射。跨 Python 仅传必要词项、语言、Prompt 和安全回执；不传数据库信息、凭据、外层业务 ID、学习内容或模型原始响应。
- 每词 30 秒、批次分析窗口 120 秒，硬截止 180 秒包含启动；模型/工具/步数预算为 20/2/32。分析窗口超时保留此前有效结果，未启动项不请求供应商。两端限制 Prompt、输入和安全回执预算。
- 只有 Python 图成功完成、宿主核对完整索引后才进入提交；最后一次取消检查与同步事务之间无 await。词条及批次报告原子提交，事务内再次查重；已提交报告的回复恢复不再调用图、模型或写词库。
- 原 TS 批量调度和词汇 Prompt 已移除。AI 导入复用分析器，通过单词 Python 图桥接相同 Prompt，保留既有逐行进度和导入事务。其他显式技能、标题与练习不变。

## 验证

按可观察行为逐项执行 TDD。真实 Python 管道测试放在根目录集成测试目录；宿主领域单元测试保留在模块的 `__tests__`。使用受控模型替身、本地 HTTP 假服务、内存 SQLite 和临时 Electron 用户目录。

覆盖 20 词与双并发、去重、配置/语言快照、合法工具内容、逐词失败和超时、取消及迟到结果、提交边界、原子报告、提交后本地恢复、真实引擎崩溃与新请求重启。伪造子进程覆盖跨运行调用、非法 call ID、越权操作、非法索引、重复索引、过量并发和提前完成标记；检查跨语言载荷不含学习内容与业务身份。
