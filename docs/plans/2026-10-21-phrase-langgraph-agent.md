# `/phrase` 完整迁移至 Python / LangGraph

- 日期：2026-10-21
- 状态：已实施
- 分支：`feature/phrase-langgraph-agent`（基于 `feature/vocabulary-langgraph-agent`）

## 实施目标

保持显式命令、选择器、多行输入、阶段提示、取消、报告、重试及历史恢复行为。Python 持有短语 Prompt 和批量图，TS 保留输入规范化、去重、内容校验、模型传输、凭据、配置快照、用量与事务。不改造 `/explore-phrase`，不增加自然语言意图识别、数据库迁移或 TS Agent 回退。所有验证仅使用临时用户目录和可丢弃数据库。

## 实现与契约

- 新增短语图 `prepare → analyze → finalize`，最多 20 项、两个 worker，每个新短语一次模型请求，已有项及重复项不请求。Prompt 显式指定解释语言及英语例句，保留 `phrase-tools-v1`、工具名和 `explantation` 字段。
- 协议升级 v4：新增 `phrase` 任务与能力、`phrase.prepare`、`model.phrase`、安全回执和 `phrase_result`。同步 Zod、生成 schema、共享契约、Python 版本、握手与运行包 manifest，旧包拒绝启动。
- `runPhrase` 共用既有 Python 子进程。任务权限隔离，最多两个同领域模型调用，校验 run/call 归属、索引、重复调用、输入与输出预算和完整终态。
- TS 运行账本持有原始输入、内容和存储身份，Python 只获取必要短语、语言、Prompt 和回执，不接收学习内容、原始模型响应、凭据或业务 ID。
- 单项 30 秒、分析窗口 120 秒、总硬截止 180 秒；模型／工具／步数预算 20／2／32。分析窗口到期后不请求未启动项，保留此前有效结果。两端校验 Prompt 4096 UTF-16 上限及输入预算。
- 完整核验图完成索引后才提交；最后取消检查和同步事务之间无 await。事务内复查冲突，短语和批次报告原子保存。提交前取消或引擎故障丢弃暂存内容；提交后的回复恢复仅使用本地报告。
- 删除 TS 短语 Prompt 与双 worker 调度，真实 Python 管道测试移至根目录集成测试，宿主超时使用可控时钟测试。

## 验证

逐项进行 TDD，首先确认新增图、短语协议与真实管道 Prompt 断言按预期失败，再接入实现。新增及迁移测试覆盖去重、规范化、双并发、语言与配置快照、工具协议、逐项失败与超时、取消、迟到结果、提交边界、原子报告、本地恢复及引擎崩溃后新请求重启。伪造子进程覆盖跨运行／调用归属、非法与重复索引、越权、词汇权限混用、过量并发、提前完成和错误终态。检查跨语言载荷不含学习内容与业务身份；冻结包烟测加入 20 项短语图，Electron 增加冻结包中英文语言规则验证。
